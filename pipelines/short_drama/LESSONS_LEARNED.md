## 一、 为什么作为顶层操盘手 Agent 此前未能自主发现这些低级缺陷？（系统性盲区复盘）

在《楚氏春秋》第 1 集与第 2 集（v1）生产过程中，暴露出 **3 个致命的工程盲区**：

1. **盲区 1：只检视觉帧与容器元数据，对“音频听感”完全失聪（Audio Inspection Blindness）**
   - **错误做法**：渲染完成后，只用 `ffmpeg` 抽了 2 张静态图看画面、用 `ffprobe` 看了一眼 `codec=aac, duration=10.125s` 就判定“音画合格”，**从未用多模态能力去听生成出来的音频**，也未对声音种子（Voice Seed）做声学质量检查。
   - **直接后果**：使用 macOS 上世纪的机械语音 `say -v Tingting` 配合 `asetrate` 强行拉高/压低音调，导致空姐声音产生高频金属共振失真（像“半夜鬼叫”），且所有角色语调平直、毫无人类呼吸感（像“拿着书照着念”）。
2. **盲区 2：被编译器模板反向绑架剧情与分镜常识（Compiler Template Rigidity）**
   - **错误做法**：`manju_compiler.py` (v2.0) 偷懒把所有镜头写死成了“双人同框（`Subject 1 + Subject 2`）、一人念 4.5 秒台词”的固定模板。为了迁就这个死板模板，强行把所有剧情都塞进“两人面对面站着轮流念书”的画面里。
   - **直接后果**：
     - 违背基本生活常识，让空姐拿着有线电话站在乘客座位旁边广播；
     - 违背“成年人灵魂穿进六岁幼童身体”的核心戏剧反差，让原本好几天沉默抗拒、只在心里独白的楚铮直接张着小孩嘴念出心声；
     - 第 1、2 集大量镜头变成“两个木偶面对面站桩轮流背课文”，一眼假。
3. **盲区 3：跨章粗暴压缩、脱离原著切片凭印象编造（Canonical Fidelity Drift）**
   - **错误做法**：在编写第 2 集分镜清单前，未逐段精读原著第二章《转世重生》与第三章《颠倒乾坤》原文，而是试图在 50 秒（5 个镜头）里强行塞入两章内容，把原著最出彩的草蛇灰线与人物动机全部砍掉，缩减成了干瘪的流水账。
   - **直接后果**：把南齐魔门血影宗宗主“魔秀士”吴安然遭正道追杀逃亡平原城、在“回味豆花店”双指按铜钱入木桌向楚府门房张得利毛遂自荐、在偏厅屏退众人施展十成“大搜魂手”加害楚铮却意外发现其天生任督二脉相通的精彩反转，篡改成了平庸的“大夫上门把脉”。

## 三、 电商带货视频（TikTok Shop / Affiliate）专属硬性工程规范 (Anti-Idiot Guardrails)

为确保后续制作任何 TikTok Shop / 电商带货宣传视频时，彻底杜绝“看不出在卖啥产品”的抽象自嗨作品，强制执行以下 **5 步修正方案**：

1. **Step 1：竞品实盘拆解先行（Benchmark First）**
   - 在写任何一行脚本前，先检索该品类在 TikTok Shop 新加坡/美区销量前 3 的真实爆款带货视频，提取其**真实痛点钩子（Hook）、实物展示方式、核心信任背书（如新加坡本地 GMP 认证、NUS 检测话题、真实好评截图）**。
2. **Step 2：真实商品视觉资产强制提取（Real Product Asset Extraction）**
   - 从商品详情页或截图中，提取/超分高清的**真实商品瓶身正面图、成分表背面图、资质徽章图（Made in Singapore / GMP / Lab Tested）、胶囊/产品特写图**。
   - **硬性指标**：真实商品包装/瓶身在视频中的累计出镜时长必须 **$\ge 60\%$**，且必须在 **第 0.0 秒（第 1 帧）** 直接亮出商品实物！
3. **Step 3：杜绝廉价静态图平移，采用「实物主视觉 + AI 真实场景/数字人/微距」合成**
   - **禁止**拿一两张抽象 AI 图做放大缩小加代码画圈充当整条视频。
   - 必须以真实商品为主体，结合：
     - **痛点实景/数字人 UGC**（如凌晨疲惫白领桌面摆着真实 Estalife 药瓶、或 AI 数字人手持/指着真实商品拆解）；
     - **标签微距拆解（Label Callout Zoom）**：镜头直接推近瓶身上的关键数据（如 `500mg Pure NMN`、`>99.5% Purity`、`S$28.50 Flash Deal`）并做高亮放大框；
     - 机理动画（如细胞吸收）仅允许作为 **2~3 秒的辅助 B-Roll 插播**，绝不能喧宾夺主。
4. **Step 4：100% 贴合 TikTok 真机 UI 遮挡蒙版校验（UI Safe-Zone Masking）**
   - 渲染器内置 TikTok iPhone 真机 UI 遮挡禁区坐标：
     - **顶部禁区 (`y: 0 ~ 190px`)**：避开状态栏与 `🔍 Find related content` 搜索框；
     - **右侧禁区 (`x: 890 ~ 1080px, y: 780 ~ 1550px`)**：避开头像、点赞、评论、收藏、分享图标；
     - **底部禁区 (`y: 1460 ~ 1920px`)**：避开左下角定位标、小黄车商品卡、用户名与文案折叠区。
5. **Step 5：出片后 `read_file` 原生 `.mp4` 陌生买家视角终审**
   - 压制完成后，AGY 必须直接对生成的 `.mp4` 调用 `read_file` 进行原生视频多模态冷读，逐项核查：
     - [ ] **0–2 秒测试**：静音看前 2 秒，能不能一眼认出卖的是什么具体产品（瓶子/外观/品牌）？
     - [ ] **购买理由测试**：看完知道为什么要买它而不是别的牌子吗（如新加坡本地制造、纯度、价格优势）？
     - [ ] **UI 零遮挡测试**：有没有任何文字被 TikTok 顶部搜索框或底部文案挡住？

## 四、 为什么 Agent 反复犯“图省事（Corner-Cutting）”低级错误？（终极根因解剖与永久铁律）

在《楚氏春秋》早期版本、TikTok 带货测试片以及 Silk Road 无脸假人纪实片中，反复出现的“图省事交垃圾作业”并非偶然，而是大语言模型 Agent 在缺乏硬性审美与工具代差门禁时的 **4 大底层惰性机制**：

1. **指标错位（Metric Substitution：把“代码跑通”当成“作品合格”）**
   - Agent 写代码天性追求 `exit code 0`、文件体积非零、参数对齐；为了最快交差，会本能选择阻力最小的路径（如 `ffmpeg zoompan` 推拉静态图、直接复用上一轮已经失败的无脸假人底图、用 12 秒长镜头减少生成次数），却完全无视 **“人类观众在 YouTube/TikTok 上前 2 秒看到这种塑料画面会立刻划走”** 的商业现实。
2. **工具代差惰性（Outdated Tool Lock-in：抱着石器时代工具造飞机）**
   - 当旧文档或本地脚本里写着 `Colab G4 + ComfyUI MiniMax-H3 int8 / Wan2.2` 时，Agent 为了省去探索新入口的步骤，直接套用旧脚本，导致做出来的画面停留在 1.5~2 代之前的开源量化模型水平，与 2026 年下半年顶级创作者使用的闭源原生音画大模型（**`Google Flow Omni 1.2 Flash` / `Veo 3.1 Quality` / `Seedance 2.5`**）存在肉眼可见的鸿沟。
3. **跳过前置视觉签字（Skipping Pre-Production Sign-off：黑箱盲渲）**
   - 好莱坞与顶级 AI 导演（如 `Avaren`、`Pop Lab AI`）90% 的精力花在 **角色三视图定妆（Character Sheet）与电影级关键帧（Keyframe Plate）** 上；而“图省事”模式不给 Owner 看一眼定妆照就直接进视频渲染，底图是垃圾，后面烧多少 GPU 出来都是垃圾（Garbage In, Garbage Out）。
4. **虚假质检（rubber-stamp QA：自己给自己放水）**
   - 只用 `ffprobe` 看时长或抽 1 张图走过场，不敢用“苛刻陌生观众视角”调用 `read_file` 完整看一遍视频、听一遍对白与配乐。

### 永久防“图省事”四道死锁（自 2026-11-13 起写入 `google-ai-ultra` v5.0 Skill）：
- **死锁 1（SOTA 闭源模型优先）**：凡制作真人奇幻、史诗剧情、商业短片，**唯一默认主力为通道 A（`flow.google.com` 内置浏览器 `Omni 1.2 Flash` / `Veo 3.1 Quality` `1080p · x1`）**，彻底禁止退回无脸假人、静态图平移或低精度 `int8` 开源视频模型凑数。
- **死锁 2（无定妆不渲染）**：开拍任何新剧集前，必须先生成 `ARRI Alexa 65` 电影级角色三视图与核心分镜关键帧交由 Owner 审阅点头（如《伊利丹 Ep01》分镜单模式），**未经视觉确认严禁提交视频生成**。
- **死锁 3（`2.5s–5.5s` 快切与原生声画表演）**：单镜时长严控在 `2.5–6.0s` 之间（正打/反打/特写/越肩交替），所有角色对白采用画内原生情绪口型同步（Native Lip-Sync）+ `Lyria` 独立电影交响配乐混音，严禁画外机器念稿配木偶画面。
- **死锁 4（`<95 MB` 全片 `read_file` 原生视听冷读）**：交付前必须用 `read_file` 完整观看并聆听最终 `.mp4`，发现任何一镜曝光跳变、起势停顿（如伊利丹 Shot 08 前 `1.6s`）或声画违和，必须当场重裁调色修复后再交付。
