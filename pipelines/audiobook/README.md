# 主线 B：小说分章切片与多角色广播剧流水线

## 核心设计理念

结合 Owner 现有的网文续写底座与内容资产，打通从“纯文本”到“可听、可分发、可变现的多角色有声广播剧”闭环：

1. **分章切片与角色剧本化（Gemini 4 / Argon）**：
   * 自动解析章节，提取独立角色名单（主角、反派、配角、旁白）；
   * 将叙述段落与对白段落打标，标注情绪（愤怒、轻蔑、温柔、冷酷）。
2. **多音色克隆与情感配音（Colab: Qwen3-TTS / CosyVoice / Fish Audio）**：
   * 为不同角色分配固定音色种子；
   * 批量将对白转为高保真音频切片。
3. **情绪背景音乐与音效（Flow Music & Freesound）**：
   * 根据剧情节奏生成匹配的环境 BGM；
   * 自动混音，生成符合播客/喜马拉雅/YouTube 分发标准的母带文件。
