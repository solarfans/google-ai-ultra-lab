## 1. 案例一：`Minireel/HGhub`（黄果短剧开源客户端）

- **信息来源**：X 推文 [`@BlackMelooo (2118617027732808184)`](https://x.com/BlackMelooo/status/2118617027732808184)
- **开源仓库**：`github.com/Minireel/HGhub` (PolyForm Noncommercial 1.0.0)
- **技术栈**：Rust + Tauri 2, Windows / macOS / Android 三端支持
- **功能定位**：黄果短剧免广告第三方竖屏播放客户端，支持列表浏览与高清播放。

### 阶段适配评估
- **当前阶段（阶段一：首发视觉渲染验证）**：❌ **暂不接入**。
  - *原因*：当前核心任务是**内容生产与渲染**（利用 Colab G4 跑通 Qwen-Image 与 MiniMax H3 影视画格），剧本文案已由《楚氏春秋》切片提供，不需要看剧播放器。
- **后续阶段（阶段二/三：商业短剧爆款拆解与分发）**：✅ **储备引入**。
  - *核心价值*：
    1. **爆款结构逆向工程**：分析热门短剧的 API 接口与元数据结构，抓取当下完播率最高的剧情黄金 3 秒钩子（Hook）、剧情反转点分布。
    2. **选品与题材库建立**：作为海外短视频与自制短剧的题材灵感库与结构对标基准。

## 2. 案例二：`DeepSeek-V4-Pro-Qwen3.5-9B-UNCENSORED-heretic`

- **信息来源**：X 推文 [`@mingzi206 (2118655841024753692)`](https://x.com/mingzi206/status/2118655841024753692)
- **模型权重**：`huggingface.co/xtools-at/DeepSeek-V4-Pro-Qwen3.5-9B-UNCENSORED-heretic`
- **模型规格**：Q4_K_M GGUF 格式，体积仅 5.6 GB，Apache 2.0 协议
- **技术亮点**：
  - 基于 DeepSeek-V4-Pro 约 25 万条高质量数据蒸馏
  - 采用 Heretic 的 ARA 算法消融对齐限制，卸除商业道德锁
  - 拒答率极低（刁钻测试集实测 97% 通过率）
  - 普通电脑（CPU/核显）或 Colab 免费 CPU 实例可流畅运行

### 阶段适配评估
- **当前阶段（阶段一：首发视觉渲染验证）**：❌ **暂不接入**。
  - *原因*：
    1. 当前技术瓶颈在 GPU 视觉生成与显存控制，不在文本生成。
    2. 针对长篇小说（如《楚氏春秋》）的高维剧情架构，Google AI Ultra 包含的 Gemini 1.5 Pro（100万+ Token）具有远超 9B 小模型的文学功底与长程记忆。
- **后续阶段（阶段二/三：商业短剧激烈冲突与反派剧本创作）**：✅ **特化引入**。
  - *核心价值*：
    1. **规避商业模型安全拒答**：商业模型（如 ChatGPT / Gemini）在生成残酷宫斗、暗杀刺杀、反派恶毒台词、血腥战斗或黑帮权谋场景时，极易触发安全策略并报错拒答。
    2. **零成本常驻**：由于仅 5.6GB，可直接在 MacBook 本地（M系列统一内存）或 Colab 免费 CPU 实例（0 CU/h）常驻运行，作为**无审查冲突对白特化生成器**。
